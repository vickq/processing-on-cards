# Data Visualization Portfolio

This repository hosts my personal data portfolio, presented as an interactive card-based interface.
Each card represents a project, experiment, or body of work developed using different tools and platforms.

The goal is to create a single public entry point for my work in data visualization, analysis, and data storytelling.

## What's Inside

- index.html - Main portfolio interface (card-based layout)
- css/ - Styling and visual identity
- js/ - Card logic, interactions, and navigation
- README.md - Documentation

## Features

- Card-based portfolio layout
- Tool-oriented organization (Tableau, R, GitHub, Web, etc.)
- Clickable cards linking to external platforms
- Lightweight implementation (pure HTML/CSS/JS)
- Easily extensible structure for future projects
- Responsive design for desktop and mobile 

## Portfolio Structure

Cards may be grouped or filtered by:

- Tool (Tableau, R, SQL, etc.)
- Type (Dashboard, Analysis, Data Art, Experiment)
- Theme (Sports, Culture, Environment, Social Data, etc.)

This structure is exploratory and may change as the portfolio grows.

## Quick Start

### Option 1: GitHub Pages (Recommended)

1. Fork this repository
2. Go to **Settings** → **Pages**
3. Under "Build and deployment":
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Click **Save**
5. Wait 1-2 minutes
6. Your calendar will be live at: `https://yourusername.github.io/repository-name/`

### Option 2: Local

Simply open `index.html` in your browser
